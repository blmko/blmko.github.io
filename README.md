# Sheets Dashboard

Дэшборды из Google Таблиц и файлов — прямо в браузере, без бэкенда.

Вставьте ссылку на Google Таблицу (доступ «все, у кого есть ссылка») или
перетащите CSV/TSV/Excel-файл — приложение само определит типы колонок и построит:

- **KPI-плитки** — сумма каждого числового показателя, дельта к предыдущему
  периоду, спарклайн;
- **динамику по времени** — отдельный график на каждый показатель
  (бакеты: день/неделя/месяц/год подбираются автоматически);
- **разбивку по категориям** — динамика топ-5 категорий + «Прочее»;
- **барчарты** — топ-10 значений категориальных колонок по любому показателю;
- **таблицу** с фильтрованным срезом и экспортом в CSV.

Фильтры (период + категории) применяются ко всему дэшборду сразу.
Светлая и тёмная темы. Ссылкой на дэшборд можно делиться: адрес вида
`https://ваш-домен/?sheet=<ссылка на таблицу>` откроет его сразу.

Данные не покидают браузер: Google Таблицы читаются через публичный
gviz-эндпоинт `docs.google.com`, файлы разбираются локально.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
```

Смоук-тесты логики (разбор gviz, вывод типов, агрегаты) — `scratchpad/smoke.mjs`
из сессии разработки; проверить вручную можно на `?demo=1`.

## Сборка и деплой

```bash
npm run build    # статика в dist/
```

`dist/` — полностью статические файлы (base `./`), их можно положить в любой
подкаталог любого веб-сервера. Никаких переменных окружения и API-ключей.

### Вариант 1: nginx на сервере

```bash
rsync -av dist/ user@server:/var/www/sheets-dashboard/
```

```nginx
server {
    listen 80;
    server_name dash.example.com;

    root /var/www/sheets-dashboard;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # ассеты Vite содержат хэш в имени — кешируем навсегда
    location /assets/ {
        expires max;
        add_header Cache-Control "public, immutable";
    }
}
```

### Вариант 2: Docker

```bash
docker build -t sheets-dashboard .
docker run -d -p 8080:80 --name sheets-dashboard sheets-dashboard
```

## Требования к таблице

- Первая строка — заголовки колонок (или закреплённая строка заголовка).
- Доступ: Файл → Настройки доступа → «Все, у кого есть ссылка» → Читатель.
- Конкретный лист выбирается параметром `#gid=…` в ссылке (как при копировании
  ссылки на лист из браузера).

## Стек

Vue 3 + Vite. Графики — собственный SVG-рендер по спецификации дата-виза
(валидированная CVD-безопасная палитра, crosshair-тултипы, таблица-двойник
у каждого графика). Excel разбирается через SheetJS (ленивый чанк — грузится
только при загрузке .xlsx).
